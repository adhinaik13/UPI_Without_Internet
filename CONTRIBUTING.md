\# Contributing to UPI Offline Mesh



Thank you for your interest! This is a research/educational prototype. Contributions are welcome, especially in the areas listed below.



\## How to Contribute



1\. Fork the repository

2\. Create a feature branch (`git checkout -b feature/amazing-thing`)

3\. Commit your changes (`git commit -m 'feat: add amazing thing'`)

4\. Push to the branch (`git push origin feature/amazing-thing`)

5\. Open a Pull Request



\## Development Setup



```bash

\# Clone

git clone https://github.com/adhinaik13/UPI\_Without\_Internet.git

cd UPI\_Without\_Internet



\# Run tests

./mvnw test



\# Run locally

./mvnw spring-boot:run



\## Areas of Interest



• Native Android transport: Bluetooth LE / WiFi Direct implementation

• Security hardening: Formal threat modeling, fuzz testing, key rotation

• Performance: Load testing, encryption benchmarks, mesh propagation latency

• Persistence: PostgreSQL migration, durable transaction ledger

• Observability: Micrometer metrics, Prometheus/Grafana dashboards



\## Code Style



• Java 17 features welcome

• Follow existing package structure

• Add tests for new features

• Update README.md if you change user-facing behavior
